# Proxy Gate

ربات سرورلس تلگرام. پروکسی نمی‌سازد و ترافیک را از خودش رد نمی‌کند. از منبع‌های عمومی لیست می‌گیرد، رتبه می‌دهد و دکمهٔ اتصال می‌فرستد.

## چه چیزی بالا می‌آید

| دکمه | معنی |
| --- | --- |
| پروکسی‌های جدید | MTProto. اول Fake-TLS که منبع از داخل ایران به آن‌ها رسیده، پورت ۴۴۳، هندشیک و مقاومت. راز تکراری کنار گذاشته می‌شود. |
| فقط ایران | همان تست‌شده‌ها، از کم‌تأخیرترین. |
| یکی از بهترین‌ها | یک MTProto با بالاترین امتیاز. |
| SOCKS5 | فقط آدرس‌هایی که ProxyScrape با فیلتر Elite و تایم‌اوت ۳ ثانیه زنده دیده. کشور اگر در hideip باشد اضافه می‌شود. وصل با یک لمس داخل تلگرام. |
| وب | HTTP الیت. تلگرام برای این نوع لینک یک‌ضرب ندارد؛ آدرس را کپی می‌کنی. |

«نشد» همان مورد را در دورهای بعد پایین می‌برد. لیست حدود ده دقیقه کش می‌شود.

تأخیر، عدد چک‌کنندهٔ منبع است نه پینگ گوشی تو.

## امنیت

پروکسی عمومی خصوصی نیست.

- روی MTProto متن چت برای صاحب پروکسی خوانا نیست، چون تا سرور تلگرام رمز است. اینکه به تلگرام وصل شده‌ای معلوم است.
- SOCKS و HTTP الیت فقط یعنی آی‌پی‌ات در هدر لو نرفته. صاحب پروکسی ترافیک را می‌بیند.
- بانک، رمز و اکانت حساس را از روی این‌ها رد نکن. برای آن کار یک پروکسی شخصی لازم است.

رازهایی که فقط شکلشان با `ee` شروع می‌شود ولی هگز نیستند Fake-TLS حساب نمی‌شوند.

## منبع‌ها

- zakky، tgmtproxy، shablin/mtproto-proxy، 0xRadikal — MTProto با وضعیت و تست ایران وقتی منبع داده باشد
- ProxyScrape elite — SOCKS5 و HTTP
- hideip.me — کشور

## اجرا

[Telegram Serverless](https://core.telegram.org/bots/serverless). توکن را داخل ریپو نگذار.

```sh
npx tgcloud push
npx tgcloud migrate --yes
```

در BotFather باید Serverless برای همین ربات روشن باشد. توکن CLI با توکن Bot API یکی نیست.

# Proxy Gate

ربات سرورلس تلگرام. پروکسی نمی‌سازد و ترافیک را از خودش رد نمی‌کند. از منبع‌های عمومی لیست می‌گیرد، رتبه می‌دهد و دکمهٔ اتصال می‌فرستد.

## چه چیزی بالا می‌آید

| دکمه | معنی |
| --- | --- |
| پروکسی‌های جدید | MTProto. اول Fake-TLS که از داخل ایران به آن‌ها رسیده، پورت ۴۴۳، هندشیک و مقاومت. راز تکراری کنار گذاشته می‌شود. |
| فقط ایران | همان تست‌شده‌ها، از کم‌تأخیرترین عدد منبع. تأخیر زیر ۲۰ میلی‌ثانیه (پینگِ کنار خود سرور) برای این مرتب‌سازی نادیده گرفته می‌شود. |
| یکی از بهترین‌ها | یک MTProto با بالاترین امتیاز. |
| SOCKS5 | فقط آدرس‌هایی که ProxyScrape با فیلتر Elite و تایم‌اوت ۳ ثانیه زنده دیده. کشور اگر در hideip باشد اضافه می‌شود. وصل با یک لمس داخل تلگرام. |
| وب | HTTP الیت. تلگرام برای این نوع لینک یک‌ضرب ندارد؛ آدرس را کپی می‌کنی. |

«نشد» همان مورد را برای همان نفر یک بار پایین می‌برد. تازه‌سازی برای هر نفر هر سه دقیقه یک بار است و هم‌زمان فقط یک سنجش اجرا می‌شود. لیست حدود ده دقیقه کش می‌شود.

تأخیر، عدد چک‌کنندهٔ منبع است نه پینگ گوشی تو.

## امنیت

لینک ربات را می‌شود داد. توکن ربات و توکن CLI را نه.

کسی که فقط با ربات حرف می‌زند نمی‌تواند توکن را بخواند، به پایگاه دیگران برسد، وب‌هوک را عوض کند، یا ربات را وادار کند به آدرس دلخواهش درخواست بزند. ربات ترافیک پروکسی را هم از خودش رد نمی‌کند. درخواست زیاد، سنجش اجباری و رأی منفی سقف دارد تا ربات بن نشود.

پروکسی عمومی خصوصی نیست.

- روی MTProto متن چت برای صاحب پروکسی خوانا نیست، چون تا سرور تلگرام رمز است. اینکه به تلگرام وصل شده‌ای معلوم است.
- SOCKS و HTTP الیت فقط یعنی آی‌پی‌ات در هدر لو نرفته. صاحب پروکسی ترافیک را می‌بیند.
- بانک، رمز و اکانت حساس را از روی این‌ها رد نکن. برای آن کار یک پروکسی شخصی لازم است.
- ربات هیچ‌وقت کد ورود، رمز یا توکن نمی‌خواهد.

راز MTProto اگر هگزِ زوج و دست‌کم ۳۲ رقم نباشد، یا همه‌اش یک حرف تکرار شده باشد، دور ریخته می‌شود. لینک اتصال را خود ربات از روی سرور و پورت و راز می‌سازد و لینک داخل فایل منبع را اعتماد نمی‌کند. میزبان باید دامنهٔ عمومی یا آی‌پی عمومی باشد.

## منبع‌ها

- zakky، tgmtproxy، shablin/mtproto-proxy، 0xRadikal (FakeTLS و stable) — MTProto با وضعیت و تست ایران وقتی منبع داده باشد
- ProxyScrape elite — SOCKS5 و HTTP
- hideip.me — کشور، نه جایگزین تست الیت

## اجرا

[Telegram Serverless](https://core.telegram.org/bots/serverless). توکن را داخل ریپو نگذار. `tgcloud login` یا متغیر `TGCLOUD_TOKEN` فقط روی ماشین خودت بماند.

```sh
npx tgcloud push
npx tgcloud migrate --yes
```

در BotFather باید Serverless برای همین ربات روشن باشد. توکن CLI با توکن Bot API یکی نیست. اگر توکن لو رفت، هر دو را عوض کن و توکن جدید را داخل گیت ننویس.
